# 📖 StoryTime v1.1

**Творческая студия для писателей, сценаристов и мастеров НРИ.**
Генераторы сюжетов, персонажей, миров и редактор проектов — всё в одном файле, полностью офлайн.

---

## ✨ Возможности

- 🎨 **3 темы**: светлая · бежевая · тёмная
- 📚 **Редактор проектов** — главы, акты, сцены, персонажи с автосохранением
- 🎯 **Конструктор сюжета** — 6 шагов + шаблоны (Путь героя, Save the Cat…)
- 🎲 **6 генераторов**: сюжет, персонаж, мир, существо, локация, имена
- 📥 **Кнопка «В проект»** — отправка из генератора прямо в проект
- 💾 **Библиотека** — поиск, фильтр, экспорт/импорт JSON
- 🌍 **14 жанров**, **12 культур имён**, **12 архетипов**, десятки черт и тайн

---

## 🚀 Установка на GitHub Pages

1. Создай репозиторий **`storytime`**
2. Залей 5 файлов: `index.html`, `style.css`, `script.js`, `data.js`, `README.md`
3. **Settings → Pages** → Source: `main` / `/ (root)` → Save
4. Сайт: `https://ТВОЙ-ЛОГИН.github.io/storytime/`

### Локально
Просто открой `index.html` в браузере. Никаких зависимостей.

## 💾 Хранение данных

Всё лежит в **localStorage** браузера:

| Ключ | Что |
|------|-----|
| `storytime-theme` | тема |
| `storytime-saved` | библиотека (до 500 записей) |
| `storytime-projects` | проекты |
| `storytime-plotbuilder` | черновик конструктора |

⚠️ Не синхронизируется между устройствами. **Регулярно экспортируй в JSON** важное.

## 🎨 Кастомизация

Добавить культуру имён — в `data.js` → `DATA.names`:
```js
elvish: {
  name: "🧝 Эльфийские",
  m: ["Леголас", "Элронд"],
  f: ["Галадриэль", "Арвен"],
  lastM: ["Листопада"],
  lastF: ["Листопада"]
}
```

Добавить жанр — в `DATA.genres`:
```js
spaceOpera: {
  name: "Космоопера",
  settings: ["галактическая империя"],
  problems: ["вторжение чужих"],
  goals: ["спасти галактику"],
  twists: ["враг — бывший друг"]
}
```

Изменить тему — переменные в `style.css` (`:root`, `[data-theme="beige"]`, `[data-theme="light"]`).
