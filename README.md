# 📖 StoryTime

Творческий помощник для писателей, сценаристов и ролевиков.
Генерирует сюжеты, персонажей, миры и имена — всё в одном месте.

## ✨ Возможности
- 🎬 Генератор сюжетов (6 жанров)
- 👤 Генератор персонажей с тайнами и слабостями
- 🌍 Генератор мира (политика, магия, конфликты)
- ✨ Рандомайзер имён (5 культур)
- 💾 Сохранение результатов в браузере
- ⬇ Экспорт в JSON
- 📱 Полностью адаптивный дизайн

## 🚀 Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub с названием `storytime`
2. Загрузи в него 4 файла: `index.html`, `style.css`, `script.js`, `README.md`
3. Зайди в **Settings → Pages**
4. В разделе **Source** выбери:
   - Branch: `main`
   - Folder: `/ (root)`
5. Нажми **Save**
6. Через минуту сайт будет доступен по адресу:
   `https://твой-логин.github.io/storytime/`

## 🛠 Локальный запуск
Просто открой `index.html` в браузере — никаких зависимостей не нужно.
