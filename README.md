# 📖 StoryTime v1.0

Творческая студия для писателей, сценаристов и мастеров НРИ.

## ✨ Что нового в v1.0
- 🎨 **Три темы**: светлая, бежевая, тёмная
- 📚 **Редактор проектов**: полноценные истории с главами, персонажами, локациями
- 🐉 **Генератор существ**: 6 типов, десятки способностей
- 🗺 **Генератор локаций**: города, руины, природа, здания
- 🎭 **14 жанров сюжета**: фэнтези, sci-fi, детектив, киберпанк и др.
- 👤 **12 архетипов персонажей** + расширенная база черт
- 🌍 **Расширенный генератор миров** (религия, экономика)
- ✨ **12 культур имён** + прозвища
- 🔍 **Поиск и фильтры** в библиотеке
- ⬆ **Импорт / экспорт** JSON
- 📥 **Кнопка «В проект»** — отправить сгенерированное прямо в проект

## 🚀 Установка на GitHub Pages

1. Создай репозиторий `storytime` на GitHub
2. Загрузи 5 файлов: `index.html`, `style.css`, `script.js`, `data.js`, `README.md`
3. **Settings → Pages** → Source: **main** / **root** → Save
4. Сайт будет доступен: `https://<твой-логин>.github.io/storytime/`

## 🛠 Локальный запуск
Просто открой `index.html` — никаких зависимостей.
