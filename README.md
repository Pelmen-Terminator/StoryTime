# 📖 StoryTime v1.4

**Студия историй для писателей, сценаристов и мастеров НРИ.** Версия 1.4 — персонализация интерфейса, редактор персонажей, интерактивная карта отношений и расширенные наборы имён.
Генераторы + редактор проектов с иерархией. Полностью офлайн.

## ✨ Возможности

- 💾 **Надёжное сохранение** — данные выживают при перезагрузке и обновлении
- 📦 **Автобэкапы** — ежедневный снимок + 5 ручных
- 📑 **Иерархия** — глава → сцена → персонаж/локация/существо
- 🎯 **Конструктор сюжета** — 6 шагов, подсказки по каждому этапу, шаблоны структур и индикатор прогресса
- 🎲 **6 генераторов** — сюжет, персонаж, мир, существо, локация, имена; 27 жанров с отдельными наборами мест, конфликтов, целей и поворотов
- 📋 **Шаблоны проектов** — Роман, Кампания НРИ, Сценарий
- 🎨 **7 тем** — светлая, бежевая, тёмная, тёмно-синяя, тёмно-зелёная, тёмно-красная и тёмно-фиолетовая
- 🗒 **История обновлений** — встроенная вкладка «Обновления»; `history.html` оставлен для совместимости
- ✍️ **Писательские подсказки** — случайные упражнения и стартовые идеи в конструкторе
- 🔗 **Карта отношений** — визуальные связи персонажей с заметками и типами отношений
- 👤 **Подробная карточка персонажа** — возраст, пол/гендер, раса, происхождение, друзья, враги, семья, мотивация и биография
- ⚙️ **Настройки отображения** — размер шрифта, ширина текста, межстрочный интервал и плотность
- 🧬 **Дополнительные поля** для описания миров, существ и локаций
- ❓ **Help-панель** — подсказки на каждом экране
- 🆘 **Онбординг** — гайд при первом запуске

## 🚀 Установка

1. Создай репозиторий `storytime`
2. Залей: `index.html`, `style.css`, `script.js`, `data.js`, `README.md`, `history.html`
3. **Settings → Pages** → `main` / root → Save
4. Сайт: `https://ТВОЙ-ЛОГИН.github.io/storytime/`

Локально: открой `index.html` в браузере.

## 💾 Сохранность данных

Все данные в **localStorage**. При перезагрузке и обновлении сайта — **сохраняются**.

| Ключ | Что |
|------|-----|
| `storytime-projects` | проекты с иерархией |
| `storytime-projects-version` | версия схемы (для миграции) |
| `storytime-saved` | библиотека |
| `storytime-theme` | тема |
| `storytime-backups` | последние 5 бэкапов |
| `storytime-onboarded` | пройден ли онбординг |

### Автобэкап
- Раз в день создаётся снимок
- Хранятся последние **5** бэкапов
- Кнопка **📦** в шапке — создать/восстановить/экспортировать

### Ручной полный бэкап
Кнопка **📦 → Экспортировать ВСЁ** — скачивает JSON с проектами, библиотекой, черновиком.

## 📑 Иерархия проекта

Каждая глава может содержать **подразделы**:

```
🎬 Акт I
  📖 Глава 1
    👤 Генри
    🗺 Таверна «Три совы»
    🐉 Тёмный дракон
  📖 Глава 2
🎬 Акт II
  ...
```

- Кнопка **＋** — добавить раздел
- Кнопка **↳** — добавить подраздел в выбранный
- Стрелка **▶/▼** — свернуть/развернуть
- Типы: акт, глава, сцена, персонаж, локация, существо, предмет, фракция, событие, заметка

## Исправление v1.3.1
- История обновлений встроена во вкладку основного сайта; старый адрес `history.html` перенаправляет на неё.
- Переключение темы защищено на случай недоступности `localStorage`; выбранная тема применяется и сохраняется при доступном хранилище.
- Улучшены размеры элементов управления, горизонтальная прокрутка вкладок и расположение выбора темы на мобильных экранах.


## Обновление v1.4

- Добавлена вкладка «Настройки»: размер шрифта, ширина основного содержимого, межстрочный интервал и плотность интерфейса. Настройки хранятся локально и применяются при следующем посещении.
- Добавлена интерактивная карта отношений. Персонажи и связи (друзья, враги, родственники, коллеги, предательство, романтические интересы, наставники, союзники, соперники и другие) сохраняются в локальном хранилище браузера. Можно выбирать узлы, добавлять примечания и удалять персонажей/связи.
- Редактор персонажа дополнен полями возраста, пола/гендера, расы/вида, происхождения, роли, друзей, врагов, родственников, союзников/коллег, внешности, мотивации и биографии. Карточку можно сохранить в библиотеку, добавить в проект или в схему отношений.
- Редакторы мира, существа и локации получили дополнительные поля для самостоятельного описания; заполненные заметки включаются в сохраняемый материал и в проект.
- Генератор имён дополнен наборами: античная Греция, средневековая Европа, арабские, корейские, китайские, научная фантастика, эльфийский и дварфийский народы.
- Интерфейс адаптирован для узких экранов: редакторы переходят в одну колонку, а большая схема отношений прокручивается горизонтально.

### Данные и приватность
Проекты, библиотека, настройки и схема отношений сохраняются в браузере текущего устройства. Они не синхронизируются автоматически между устройствами. Перед очисткой данных браузера экспортируй материалы из библиотеки.


### Наборы имён v1.4
Добавлены наборы для античной Греции, средневековой Европы, арабских, корейских и китайских имён, научной фантастики, эльфийского и дварфийского народов. Это творческие подборки для вдохновения, а не исчерпывающие лингвистические базы.


### Уточнение редактора собственного сюжета

В разделе «Мои проекты» добавлена «Энциклопедия моего сюжета». Она хранит персонажей, локации, события, организации/фракции, предметы и существ внутри выбранного проекта. Для персонажей доступны возраст, пол/гендер, раса/вид, внешность, характер, цели, биография, друзья, враги, родственники и заметки. Можно связывать персонажей отношениями прямо в проекте. Эти элементы не являются результатами отдельного генератора и сохраняются вместе с данными проекта. Номер версии не изменён.
